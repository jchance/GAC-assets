# QR Codes

QR codes for flyers, signs, slides, and anything else you print or share. Each one is black on white with a white border built in, so it scans on any background.

Use the SVG for print and design work, since it stays sharp at any size. The PNG is 1184 pixels square, for Word, Canva, and slides.

## Printing

- Keep a code at least 1 inch wide, and bigger if people will scan it from across a table or a room.
- Don't crop the white border or put the code on a busy photo. Scanners need that quiet space.
- Scan your first print with a phone before you print a stack.
