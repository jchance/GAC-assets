# Logos

Official Griffin Arts Council logo files. Available in color and grayscale variants, with horizontal, stacked, and G-logo layouts.

## Usage Guidelines

- Use the **color** versions on white or light backgrounds
- Use the **grayscale** versions on dark backgrounds or for single-color printing
- `.png` files for digital/web use
- `.ai` files for print and design work (Adobe Illustrator)
- `@2x` variants are high-DPI (Retina) versions
