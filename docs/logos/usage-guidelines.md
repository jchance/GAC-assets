# Griffin Arts Council Logo Usage Guidelines

You must follow these standards to maintain consistent branding across all print, digital, and promotional media.

## 1. Approved Logo Configurations

### Primary Full Lockup

Features the stylized GAC lettermark with the integrated paintbrush icon above the stacked Griffin Arts Council text wordmark. Use this configuration on official documents, presentation covers, and main website banners.

### Horizontal Lockup

Features the standalone G paintbrush icon on the left, separated by a vertical dividing line from the stacked three-line Griffin Arts Council wordmark. Use this configuration for website navigation headers, email signatures, letterheads, and horizontal sponsorship banners.

### G Logo

Features the standalone G paintbrush mark with the Griffin Arts Council text curved along the bottom rim. Use this mark for social media profile avatars, event badges, stickers, and small-format merchandise.

### Grayscale Variations

Each configuration includes an approved grayscale version. Use grayscale versions exclusively for single-color print, black-and-white forms, newsprint, or dark backgrounds requiring high contrast.

## 3. Clear Space and Minimum Sizing

- Always maintain clear space around the logo equal to the width of the letter **C** in the primary mark. Keep this zone free of text, patterns, and trim edges.
- Set the minimum reproduction size for the primary lockup at **1.25 inches wide** for print or **120 pixels wide** for digital screens.
- Set the minimum reproduction size for the G Logo at **0.75 inches wide** for print or **64 pixels wide** for digital screens.

## 4. Rules for Unacceptable Use

- Do not stretch, squeeze, skew, or distort the proportions of the artwork.
- Do not rearrange, separate, or resize individual elements within the lockups.
- Do not alter the approved brand color assignments or replace colors.
- Do not add drop shadows, outer glows, strokes, or gradient fills to the vector assets.
- Do not place the full-color logo over busy photographic backgrounds or low-contrast colors.
